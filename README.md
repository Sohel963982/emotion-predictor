# Emotion Predictor

##  Overview

Emotion Predictor is a Machine Learning and Natural Language Processing (NLP) project that analyzes textual input and predicts the emotion expressed in the text.

The application processes user-provided text and classifies it into different emotion categories using a trained Machine Learning model.

##  Features

- Text preprocessing
- Tokenization and stopword removal
- Feature extraction using Bag of Words
- Machine Learning-based emotion classification
- Predicts emotions from user input
- Interactive web interface using Streamlit

##  Technologies Used

- Python
- Pandas
- Scikit-learn
- NLTK
- Streamlit
- Machine Learning
- Natural Language Processing (NLP)
